# Ida en Chris Vakantie Spelletjes

Een app om bij te houden wie welk spel wint tijdens de vakantie van Ida en Chris.

## Status

Fase: **Spec**. De formele specificatie staat in [`spec.md`](spec.md) — Gherkin-features
plus de niet-functionele acceptance criteria.

## Volgende stap

Voordat de app gebouwd kan worden met een gevulde lijst moet de **initiële Spellenlijst**
nog worden aangeleverd (zie "Niet in scope / uitgesteld" in `spec.md`).

## Achtergrond

Opgesteld volgens het Vibe · Spec · Harness framework. De spec is afgeleid van de
Vibe-fase output (`scenarios.md` en `ubiquitous_language.md`) en gebruikt consistent
de Ubiquitous Language van het domein: Spel, Spellenlijst, Winnaar, Stand, Eindstand,
Uitslag invoeren, Corrigeren, Persistente opslag.
